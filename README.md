## 👨‍💻 About me

I'm a **Computer Science master's student** and **Research Assistant at Hanoi University of Science and Technology (HUST)**. I work close to the networking layer, where systems have to be measurable, resilient and clear enough to debug under real constraints.

- 🔬 **Research:** wireless sensor networks, SDN-based architectures, IoT communication and simulation-based performance evaluation
- 🛠️ **Building:** software tools, embedded prototypes and interactive web experiments
- 🎮 **Previously:** game developer intern at Gameloft Hanoi and software developer intern at BRAVO Software
- 🌐 **More about me:** [vuducan.qzz.io](https://vuducan.qzz.io)
